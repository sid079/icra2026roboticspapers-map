The evolution that matters most — the Data Bottleneck

Read top to bottom: the field first tries to edit pixels (Masquerade), then co-train + retarget (EMMA, ReActor), then change the representation so the human/robot gap vanishes (HumanEgo) — while a counter-camp just makes teleop cheap and global (COBALT). Same problem, shifting bet.
